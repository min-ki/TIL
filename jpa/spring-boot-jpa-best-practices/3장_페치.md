# 3장. 페치

## 항목 21: 다이렉트 페치 사용 방법

다이렉트 페칭 (direct fetching) 또는 ID로 가져오기
> 식별자를 알고 있고 지연 연관관계가 현재 영속성 컨텍스트에 필요없을 때 엔티티를 가져오는 바람직한 방법

다이렉트 페칭은 기본적으로 아래와 같이 로딩하거나 FetchType에 따라 로딩한다.
- `@OneToMany`, `@ManyToMany`는 Lazy 로딩
- `@ManyToOne`, `@OneToOne`은 Eager 로딩


가장 좋은 방법은 모든 연관관계를 Lazy하게 설정하고, **수동 페치(manual fetching) 전략 사용**

### ID로 엔티티를 가져오는 방법

```java
@Entity
public class Author {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private int age;
    private String name;
    private String genre;
}
```

#### 1. 스프링 데이터를 통해 다이렉트 페치
내장된 `findById()` 메서드를 사용해 스프링 데이터에서 다이렉트 페치를 수행할 수 있다.

```java
@Repository
public interface AuthorRepository extends JpaRepository<Author, Long> {}

// authorRepository의 findById 사용
// 반환 타입은 Optional인 것을 눈여겨보자.
Optional<Author> author = authorRepository.findById(1L);

// 위의 결과로 나가는 쿼리
SELECT
    author0_.id as id1_0_0_,
    author0_.age as age2_0_0_,
    author0_.genre as genre3_0_0_,
    author0_.name as name4_0_0_
FROM author author0_
WHERE author0_.id = ?
```

> findById는 내부적으로 EntityManager.find() 메서드를 사용한다.

#### 2. EntityManager를 통한 다이렉트 페치

```java
@Repository
@Transactional(readOnly=true)
public class Dao<T, ID extends Serializable> implements GenericDao<T, ID> {
    @PersistenceContext // 이 어노테이션을 통해 EntityManager를 주입받을 수 있다.
    private EntityManager entityManager;

    @Override
    public Optional<T> find(Class<T> clazz, ID id) {
        if (id == null) {
            throw new IllegalArgumentException("ID cannot be null");
        }

        // entityManager의 find 메서드를 사용해 엔티티를 가져온다.
        return Optional.ofNullable(entityManager.find(clazz, id));
    }
}
```

#### 3. 하이버네이트 Session을 통한 다이렉트 페치

```java
@Repository
@Transactional(readOnly=true)
public class Dao<T, ID extends Serializable> implements GenericDao<T, ID> {
    @PersistenceContext
    private EntityManager entityManager;

    @Override
    public Optional<T> findViaSession(Class<T> clazz, ID id) {
        if (id == null) {
            throw new IllegalArgumentException("ID cannot be null");
        }

        // Session을 얻기 위해 EntityManager를 언랩핑한다.
        Session session = entityManager.unwrap(Session.class);
        // Session의 get 메서드를 사용해 엔티티를 가져온다.
        return Optional.ofNullable(session.get(clazz, id));
    }
}
```

- 처음 가져온 엔티티는 영속성 컨텍스트 (1차 캐시)에 캐시, 동일한 엔티티의 계속되는 가져오기는 영속성 컨텍스트에서 수행
